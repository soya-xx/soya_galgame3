# 文笔规范 v2（2026-06-13 用户拍板）—— 大白话 · 去排比 · 侧面动作

> 用户原话：现在文笔太装逼。大部分剧情用简单网文大白话，直接简单。**不要有任何
> 能被看似描述成排比的句子**。只有非常关键的时刻，才用华丽/有艺术气息的词藻。
> 所有描写尽量用**侧面描写 + 动作描写**，不要平铺直叙，不要看上去像把大纲铺在面前。
> 这是视觉小说，文笔不足处可用 GPT Image 2 出图承载场景（出图后自审可用性/贴合/一致）。

## 六条硬规矩

1. **大白话优先**。一句话能说清就别绕。像普通网文：直接、好懂、口语。
2. **全篇禁排比**。不准"X。Y。Z。"三连，不准重复句式叠加，不准"为……为……为……"。
   一个意思，说一遍就够。哪怕高光时刻，也用**一个**强意象，别堆三个。
3. **华丽词藻只留给极少数高光**（见下"高光清单"）。其余一律朴素，能省就省。
4. **侧面 + 动作，不平铺直叙**。不要直接"告诉"情绪和结论；用动作、反应、环境、
   一个具体细节去"显示"。把"他很慌"写成"他手里的碗，没端稳"。
5. **画面优先**。难写的大场面，宁可交给一张 CG，文字退半步、只点一句。
6. **保留既有硬约束**：每行≤48显示字符；禁 AI 味（不是…而是…/本质/范式/涌现等）；
   口语；人物语癖（向向撒谎带"喵"、称"主人"）；**不动** DSL 结构/选项/flag/cg/fx。

## 高光清单（仅这些地方可以"美"，且仍不许排比）

序章·剑骨重铸与初次现形；二章·灵泉；一章·月下现形；三章·初吻盖章；
四章·燃丹；终章·万剑归宗那一剑、顾长生之死、真结局晨光之吻。
—— 除此之外，全部大白话。

| --- | --- | --- |
| 排比三连 | 金光碎了。云海碎了。你碎了。 | 金光灭了。你听见自己骨头里，咔一声。 |

| 陈词滥调 | 柳长青的眼睛像两口枯井。 | 柳长青看着你，眼里没什么光。 |
| 平铺直叙 | 那张傲慢的脸上，第一次有了别的东西。 | 他没说话，攥着剑穗的手，紧了紧。 |
| 平铺直叙 | 他眼眶通红，哪还有半分演武场上的横。 | 他眼睛红着，声音抖，跟演武场上判若两人。 |
| 堆砌 | 月白剑光落下来，把整座演武场照成了月夜。 | 剑光一闪，全场亮了一下，又暗下去。 |

## 侧面/动作描写口诀

- 写情绪 → 写**身体**：手抖、耳朵塌、尾巴炸、咽口水、攥紧、别开脸。
- 写厉害 → 写**别人的反应**：全场静了、对手退三步、有人倒吸气。
- 写气氛 → 写**一个具体物件**：没端稳的碗、灭了一半的灯笼、地上的水洼。
- 写难过 → **别写"难过"**，写她"把鱼干推给你，自己没吃"。
