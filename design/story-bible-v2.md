# 《剑神三千年》故事圣经 v2 —— 真两难 · 真代价 · 活的世界

> v1 见 [story-bible.md](story-bible.md)。v2 不改世界观、不改 8 结局、不改引擎与
> DSL、**不改分支点按钮文案与走向**（route 模拟靠它）。v2 只做四件事：
> ①把每个选择改成真两难；②让选择有真实代价（救人=中性，带涟漪）；
> ③把每个角色写成每章都在"活着"的人，含亦正亦邪/烂人真心；④文笔重打磨。

---

## 0. 修订总纲（写作时逐条自检）

1. **不剧透**：选项前的独白**禁止**预告利弊（删掉"说真话=多盟友+把柄"这类）。
   玩家从已铺垫的情境自己权衡。
2. **不补刀**：选完一边，**禁止**任何角色说"你刚才为什么不选另一个"。
   （向向尤其禁。她可以有情绪，但不替玩家评判对错。）
3. **双向铺垫**：每个选择，两个选项都要在**它出现之前**就被埋好"想选它的理由"。
4. **双向代价**：每条分支都要付出**能被玩家看见**的东西——盟友反目 / 好心害人 /
   关掉一条好结局 / 失去一段真相。代价靠演，不靠数字面板。
5. **救=中性**：救活一个人只是"他活着"，不等于好结果。被救者会按**他自己的**
   是非观行事，可能酿出他以为对、实则坏的涟漪。
6. **变量即代价**：jian/ban/truth/flag 本就在卡结局（见 v1 矩阵）。v2 不弱化这套，
   而是把"少拿到的真相""反目的盟友"**演成剧情里能摸到的损失**，而非藏起来。
7. **活的世界**：每个具名角色，每章都有自己的目的在推进，哪怕只一笔。
8. **大白话**：每行 ≤48 显示字符；禁"不是…而是…/本质/范式/涌现"等 AI 味。
   长想法拆成多次点击。角色像人：怕死、贪利、要面子、护短、会自欺。

## 1. 角色名册 v2（含新增）

### 新增·钱通（烂人真心 · 主体）—— 需新立绘+CG
- **身份**：外门旁支穷弟子，靠给圣教"金眼"耳目通风报信，把同门一个个卖上去，
  换自己升内门、换家里免饥。绰号"钱串子"。
- **想要**：活下去，并让爹娘弟妹活下去。他的恶，全是怕。
- **伤口**：早年眼睁睁看着家里饿死过人。从此信一条：「不卖别人，被卖的就是我。」
- **面具**：见人三分笑，谁红跟谁，话密、手脚勤、专挑软的踩。
- **反讽**：他卖了一路人，圣教却把**他**也写进了名册——工具用完即弃。
- **弧光**：全程为自己活的人，在飞升台上做**唯一一件**不为自己的事
  （替名册上的孩子解开锁灵链 / 替主角挡一击 / 当众揭穿真相，明知会死）。
  一个烂人，真心一次。
- **种子机制**：若主角早期对他动过一次"不划算的善"（见选择点 ⑫ 衍生 / 救阿萝线），
  他的临终一善是**呼应**（"那次你没踩我，我记着"）；若主角全程冷硬，他的临终一善
  是**纯赎罪**，更苦（"我这辈子没干过一件人事……就这一件吧"）。两版都升华，味不同。

### 新增·阿萝（名册上的孩子）—— 旁白为主，立绘可选(stretch)
- 十二岁记名弟子，被选中"登天"，欢天喜地以为是天大的福气，不知是去死。
- 功能：把"飞升祭=献祭"从概念变成**一张具体的脸**。她的存在让"救/不救""坦白/不坦白"
  都多一层重量。她可能死于"救沈青澜"的涟漪，也可能被钱通的临终一善救下。

### 顾长生（圣主 · 反派 · 深化"种子机制"）
- v1 设定不变（与天做交易、夜夜长跪、黑暗镜像）。
- **新增·种子**：玄一向他回报"师兄"的为人。主角早期累积的"人味"（ban/善行 flag）
  会改写玄一口中的师兄——
  - 若主角选了**人**（ban 高 / 救人 / 还人情）：顾长生发现师兄这一世**变了**，
    变成了他当年没敢做的样子（选人而非选力）。这击碎他三千年的自我开脱
    （"我杀他，是因为只有冷剑才扛得住天"）。→ 终章他**主动**帮一把
    （递柱钥/拖住天/真心托剑），死得像个赎清了的人。
  - 若主角选了**力**（jian 高 / 冷硬）：顾长生在他身上看见**第二个自己**，
    最后一句仍是冰冷的"你我终究一样的人"（END_ASH/DEMON 既有基调）。
- 一句话：**主角越像人，敌人越能被救回来；主角越像神，敌人就只是面镜子。**

### 玄一（圣使 · 信仰崩塌）
- v1 不变（孤儿，被顾长生从死人堆里捡出，眼里只有贡品成色）。

### 沈青澜（傲慢→觉醒 · 灰度成长）

### 向向（女主 · 去补刀化）

## 2. 选择点两难矩阵（23 处）

> 格式：**【铺垫A / 铺垫B】→【代价A / 代价B】→【涟漪】→【删除】**。
> 两个旗舰给到样板级；其余给关键设计点，phase 2 据此扩写。
> 所有按钮文案、fx、走向**不动**（route 模拟依赖）。

### 旗舰① ⑯ 柳长青坦白（ch3：是 / 长老认错人了）

**提前铺垫（一、二章埋，三章收）——两种互斥读法同时成立：**
- *危险读法*：① 柳是执法长老，手上有人命。埋一桩旧案——三年前有个外门弟子"撞见了
  不该撞见的东西"，柳"查"过之后，那人就"病故"了，卷宗封存。是伸张正义，还是灭口？
  没人说得清。② 重写 [ch1.js:191](web/script/ch1.js#L191)：他私自借出**你的**坠崖卷宗——
  到底是护你，还是在替圣教建档？③ 二章夜宴他替你挡了一句参奏（既有 `liu_cover`），
  但写得暧昧：是回护，还是把你攥在手里？
- *渊源读法*：① 他左脸（或手背）一道旧烧伤，看见秋水剑意切口时，捏卷宗的手在抖。
  ② 有人传柳家祖宅夜夜点一盏不灭的灯，"等一个早死了三千年的人"。③ 他验剑桩切口
  验得过久，像在认一件旧物，而非查一桩案。
  —— 写得**诡异、克制、不写暖**，让玩家疑心"有渊源"却**不敢断定是敌是友**。

**选择处（删 [ch3.js:339-340](web/script/ch3.js#L339)）：**
- 删 `（说真话，多一个三千年的盟友，和一个把柄。）` `（不认，他终究只是"怀疑"。）`
- 换成两边都揪心的当下：雨里，老人那张看不透的脸；你心口的旧伤在跳——
  **上一个让你"信得过"的人，一剑穿了你的心。**

**真实代价：**
- **坦白（是）**：得柳长青 + 柳家残卷（真相大块）+ 终章柳家三代藏剑。**代价**——他当夜
  公开烧执法令、与宗门决裂，等于把"剑首归来"四个字甩到台面上；圣教耳目本就在山中，
  **打草惊蛇**：玄一提前开祭、宗门更慌着交人，**有人为这份张扬付账**（可挂在四章
  宗门投票更快、或老周头被牵连）。信他、靠他，是有重量的。
- **不坦白（长老认错人了）**：守住秘密，他终究只是"怀疑"。**代价**——丢残卷（truth-2、
  无 liumeng）⇒ 真相≥6 与 END_ALLY 实打实变难；终章少柳家一臂之力与一匣子剑；
  且**柳长青不会停**——他独自去查圣教，反受其害（埋一场他单枪匹马、回来时带伤/带
  噩耗的戏）。你保住了自己，却把一个老人推去独行。
- **删补刀**：删向向 `主人，为什么不认？`（[ch3.js:382](web/script/ch3.js#L382)）。
  改成她沉默地把尾巴卷上你手腕——她也不知道该信谁。

### 旗舰② ⑮ 救沈青澜（ch3：救 / 转身走）—— "救=中性"样板

**提前铺垫：**
- 救的理由：他在拦路问剑那场（⑨）若被点拨，已显出"剑痴而非纨绔"的底子；他被沈家
  当投资品，是另一个被命运摁着的人。崖顶有沈家的人≠这个少年有罪。
- 不救的理由：崖顶那笔账（[ch1.js:403](web/script/ch1.js#L403)）；他口口声声"虫豸"；
  救一个沈家的人，等于给仇家续了一口气——你凭什么替三年前的自己原谅？

**真实代价（核心改造：救≠好结果）：**
- **救（save_shen）**：他活。可他**按自己的是非观**行事——感念你、又恨透了飞升祭，
  便**过早**当众撕破飞升祭真相 / 公开忤逆沈家（**他以为对的好事**）。后果：沈家与
  圣教提前反扑，**阿萝（或另一名册孩子）成了杀鸡儆猴的那只鸡**。你救了一个好人，
  好人做了一件"好事"，好事却踩塌了别处。⇒ 玩家明确肉疼。（机制上仍给 jiushen，
  保留 END_ALLY 入口——代价是情感的、是阿萝那条命，不是关线。）
- **不救（leave_shen）**：你收了"崖顶利息"，心冷一分（向顾长生靠近一步，呼应种子）。
  **代价**——失沈青澜这一终章助力与 END_ALLY；他侥幸生还、知道有人见死不救
  （既有），成另一种变数，日后反咬一口。
- **删**：救后他那句过于顺滑的"这条命记下了"保留，但补一笔他眼里的**偏执**，
  为他日后"好心办坏事"埋引线。

### 其余选择点（关键设计点）

- **① 让它进来 / 关窗**（ch0）：铺垫两读——"妖物索命"是修行界铁律（关窗合理）vs
  它认人的眼神（让进合理）。代价：关窗→她淋一夜雨、猫记仇一晚（既有，保留，做足）；
  让进→你违了修士最基本的自保律，心里清楚这是赌命。两边都不写"对"。
- **② 签 / 问清楚再签 / 让她走**（ch0）：删"白送力量=馅饼"的暗示别太指向。让"让她走"
  有真理由——被信任的人杀过一次的人，凭什么再签一份来历不明的契约？（refuse2 →
  END_REFUSE，是一条**完整自洽**的"不打扰你"温柔线，不是惩罚。）
- **③ 接 / 忍下来**（ch1 赌局）：接→当众露锋、引柳长青与圣教耳目侧目（代价=暴露）；
  忍→吞一口气、被全场嗤笑、赵虎更嚣张（代价=气与势）。删"猎人蹲一晚为一枪"这类
  过度自洽的自我安慰，留一点"忍得不甘"。
- **④ 买鱼干 / 攒着买剑**（ch1）：删"剑是死的先喂活的"这类盖棺定论。两边都成立：
  鱼干=此刻的她；剑=大会的命。买剑→她嘴上懂事、尾巴出卖失落（既有，保留）。
- **⑤ 装侥幸 / 不解释**（ch1 柳首次盘问）：与 ⑯ 联动——这里玩家对柳的第一次态度，
  影响他后续是"盯你"还是"护你"的暧昧走向。删过度提示。
- **⑥ 盯着看 / 移开眼**（ch1 月下）：纯升温向，弱代价；保留喜剧，删轻浮，move 体面。
- **⑦ 摸耳朵 / 忍住**（ch1）：同上，糖向。
- **⑧ 藏拙 / 锋芒 / 认输**（ch2 压轴）：三向已是好两难。强化代价：锋芒→圣教金眼当场
  记名（既有），玄一三章直接点你；藏拙→沈青澜与柳长青疑心更重、暗处黑衣人提前离席
  （既有）；认输→沈家"不需要你赢，只需要你可疑"，当夜杀手上门（既有 END_ARENA）。
  保留并写足"三条都像对的"。
- **⑨ 指点一句 / 不说**（ch2 拦路问剑）：点拨=种沈青澜成长的种子（坊市回收"顶撞父亲"）；
  不说=守拙、但断了一条结盟引线。删"顺手而已"的轻佻收尾里过强的自我表扬。
- **⑩ 十倍碾过去 / 钓他抬价**（ch2 拍卖）：碾→痛快、露财、结死仇沈家管事；
  钓→省钱、得残谱情报（truth）、但把人往死里羞辱，结的仇一样深。两种爽，两种祸。
- **⑪ 立刻转身 / 愣在原地**（ch2 灵泉）：糖向喜剧；保留。
- **⑫ 拦下 / 装没看见**（ch2 赵虎偷钱）+ 衍生（送执法堂 / 给他一次机会）：
  **这是"种子"与"救=中性"的小考场**。装没看见→他堕落断手投圣教（doom，既有）；
  拦下→送官（doom）或给机会（mercy 种子）。**新增涟漪**：给机会救的不只是赵虎，
  连带**阿萝**（赵虎欠的赌坊正要拿阿萝家抵债）——把"善"接到一张具体的脸上，
  也为钱通/阿萝线接引。代价：给机会要你自掏五十灵石+担保（既有），是真金白银的善。
- **⑬ 上座 / 末座 / 不去**（ch3 夜宴）：上座→近圣使、被验货（金枣，既有）、暴露；
  末座→拣到执事醉话真相（既有）、安全但够不着；不去→把今晚给自己人、ban+、
  却**缺席**让柳长青独自替你挡参奏（liu_cover）——你的安逸是别人在扛。三向都有得有失。
- **⑭ 把丹药塞给他 / 尊重他**（ch3 老周头母病）：**"救=中性"的安静一课**。塞丹药→
  老太太多撑一程、走得安稳（既有），但你花掉一颗续命丹（大会/逃命可能用得上的命）；
  尊重他→你陪坐、不越界（既有），老人自己走完这段路。删任何"哪个更对"的暗示——
  这一题**故意**没有正确答案。
- **⑯ 见旗舰①。**
- **⑰ 摊牌 / 装不知道 / 封印面板**（ch3 妖丹真相）：三向已是好两难（既有）。
  强化：摊牌→约定+初吻盖章（糖，既有），但她从此把"烧本源"摆到台面上，更敢烧；
  装不知道→你独自背秘密、暗自不用面板（既有），她蒙在鼓里继续烧；
  封印面板→你主动变弱、用自己的骨头走（既有），圣教在前面，这是拿命赌气。
- **⑱ 拔剑 / 周旋**（ch4 玄一摊牌）：拔剑→印证实力差、被宽限三日（既有）；
  周旋→套出"圣主夜夜长跪"真相（既有，顾长生种子的关键情报）。删过强提示。
- **⑲ 为她活 / 为恨活**（ch4 灵魂黑夜）：弧光分水岭。为恨活+jian≥8+ban<10 → END_DEMON
  入口（既有）。强化：为恨活不是"错"，是一个被背叛两次的人最真实的反应；为她活也
  不是"对"，是把天下重新扛上肩。两边都让玩家懂。
- **⑳ 直取飞升台 / 带她走 / 把她托付给周伯**（ch4）：带她走（ban≥12）→ END_LEAVE
  完整温柔线（既有，非惩罚）；托付周伯→solo 线（既有）；直取→主线。三向都自洽。
