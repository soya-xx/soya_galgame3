# 人物审核 · 钱通（烂人真心 #1 · 卖同门求生）

审核范围：ch0–ch5 + endings.js。本轮重点：ch4 qian_save 羁绊场景 + END_QIAN。

---

## 一、生平背景 / 生平

外门旁支穷弟子，绰号"钱串子"。靠给圣教"金眼"耳目通风报信，把同门一个个卖上去换上位/换家里免饥。**本轮新增背景（达标）**：幼时眼睁睁看家里饿死过人，从此信"不卖别人，被卖的就是我"（ch4 qian_save，ch4.js:547-548）。另 ch2 巷口出卖王二时漏过一句"当年我妹病死就差这半袋"（ch2.js:207）。

**完整性判断：合格。** "看着家人饿死→恶全是怕逼的"把他的谄媚、卖人、专踩软的都解释成生存恐惧，灰度成立。反讽设计到位：他卖了一路人，圣教把他也写进名册（工具用完即弃，ch3 cg_qian_roster）。

---

## 三、独立线 / 立场

钱通的世界观"不卖别人就被卖"是独立且自洽的生存哲学，不依附主角。他的转变不是被主角说服，而是被"有人无理由给他一碗水/一条活路"撬动——qian_save 后"你卖人是为了活，我给你活，你卖谁"一句击穿他的生存逻辑。**独立线达标。**

---

## 四、弧光曲线

一章（谄媚踩底层）→ 二章（巷口卖王二，灰度建立）→ 三章（名册有自己名、笑容碎裂"卖人的也是货"）→ 四章（窗外跪求；qian_kind 递水种子 / qian_save 给活路 / qian_cold 由他去）→ 终章（飞升台扑过去替孩子挡金光，腰是直的）。

**双版临终一善（达标，story-bible-v2 种子机制）**：
- 呼应版（qian_seed 递过水）：ch5 qian_echo"那碗水我还没还，这群崽子我替你护下了"。
- 赎罪版（无种子）：ch5 qian_atone"我这辈子没干过人事，就这一件吧"。
两版都升华，味不同，设计精准。

**本轮 qian_save 升级**：相比 qian_kind（只递水=种子），qian_save 是给真活路（腰牌+旧道）+他自曝饿死背景+腰比来时直了些。这解锁 END_QIAN 专属结局（"走脱了又回来送命"），把烂人真心推到极致。

## 五、玩家感受

从"最该死的钱串子"到"被怕逼成恶、临了认了账的可怜人"。END_QIAN"我跑出去半里又回来了，这条命你给的，我想花得像个人"——烂人真心的天花板。阿萝给他立"钱通，好人，之墓"（学写字三个月头一句）催泪。**活人，达标。**

## 六、选择影响矩阵

| 选择 | 兑现 | 核验 |
|---|---|---|
| 递碗水(qian_kind, qian_seed) | 终章 qian_echo 呼应版 | ✓ |
| 给活路(qian_save, qianbond) | END_QIAN 入口+赎罪 | ✓ |
| 由他去(qian_cold) | 矮下去、佝偻离开 | ✓ |
| qian_seed(无 qianbond) | 终章 sever 线 qian_echo | ✓ |

**核验通过（角色层）。**

**⚠ 设计观察（建议级，非 bug）**：END_QIAN 仅在 ch5 bond 路由命中 qianbond 时触发，该路由只在 `sever` 下游可达（经 npm test 验证可达，属设计意图）。副作用：拿了 qianbond 却终章选烧/接位则不兑现。详见 AUDIT-SUMMARY 建议项。

**⚠ 逻辑断点（建议级，需确认）**：终章 sever 线 ch5.js:347-371 的"钱通飞升台扑过去挡金光"段落是**无条件执行**的（在 sever_go 主链上，无 cond 包裹），只按 `qian_seed` 分 echo/atone 两版（ch5.js:354）。问题集中在 **qian_cold（由他去）** 玩家：既无 qian_seed 也无 qianbond，落 fallback `qian_atone`（赎罪版"我这辈子没干过人事"）。但 qian_cold 线钱通是被主角冷漠拒绝后佝偻离开的，他凭什么出现在飞升台替孩子挡金光？**临终一善对 qian_cold 玩家也照常上演，但缺动机铺垫**——他没拿到主角的活路。这是"善行兑现脱离前因"的小断点。（注：qianbond 玩家会先过这段、再被 bond 路由送进 END_QIAN，属正常；qian_seed 玩家走呼应版，动机充分。）建议为 qian_cold 补一句动机铺垫（如"他也在名册队列里、临了改了主意"），或将 atone 版收窄到非 qian_cold 才演。
