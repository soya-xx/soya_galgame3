# 人物审核 · 老周头（道德锚 · 主题陈述者）

审核范围：ch0–ch5 + endings.js。本轮重点：ch3 zhou_vigil 羁绊场景 + END_ZHOU。

---

## 一、生平背景 / 生平

杂役院烧火的瘸腿老头。**本轮新增背景（达标）**：年轻时是外门头几名的剑苗子，那年娘瘫了，喂饭翻身接屎尿，剑一放就是二十年（ch3 zhou_vigil，ch3.js:602-604）。主题台词："剑再快，也得有人给你递碗热水。我娘那碗热水，我递了二十年，值。"

**完整性判断：合格。** "天才放下剑二十年养瘫娘"把他作为"道德锚/主题陈述者"的资格立住了——他不是没见识的老仆，是主动选了"人"而非"剑"的过来人，所以他的主题台词有分量、不说教。

---

**总体：达标。** 一个烧火老头每章一笔把主题坐实，无说教腔。

---

## 三、独立线 / 立场

他的世界观"扫干净自己脚下这块就不亏""剑再快也得有人递热水"是完全独立、贯穿全本的价值观，且与主角"力量解决一切"形成对照——他是把主角从神焐回人的关键外部力量。**独立线达标。**

---

## 四、弧光曲线

老周头是"锚"型角色，弧光不在他自己变，而在他**一次次坐实主题、并在关键处反推主角**：序章（暖场）→一章（递红薯说主题+自曝放剑二十年）→三章（母病：赠丹/守夜/尊重）→四章（投票拍桌+屋顶"现在递水的换成我咯"回收主题）→终章（送馒头；solo线千里送猫殁于途）。

**本轮 zhou_vigil 升级（达标）**：相比 zhou_give（塞丹）/zhou_respect（尊重），zhou_vigil 是主角陪守一夜+老头自曝"放剑二十年养瘫娘"背景+老太太走时"那只手又焐了很久"。这把主题从"台词"变成"亲历"，并解锁 END_ZHOU。

---

## 五、玩家感受

老周头是全本的"暖源"。"剑再快也得有人递碗热水"反复回收却不腻。END_ZHOU 老人怀里那只没凉的烤红薯+"猫我给你送到了"+"灶上还给你留着饭"——朴素到极致的催泪。**活人，达标。**

## 六、选择影响矩阵

| 选择 | 兑现 | 核验 |
|---|---|---|
| 塞丹(zhou_give, zhou_med) | 老太太走得安稳、回赠剑穗；ch4 屋顶 sui_yes 剑穗回收 | ✓ |
| 陪守夜(zhou_vigil, zhoubond) | 老太太走时焐手；END_ZHOU 入口 | ✓ |
| 尊重他(zhou_respect) | 自己走完、坦白"动过偷丹歪心思到底没下手" | ✓ |
| zhou_med | ch4 sui_yes 剑穗"穗还在剑就会有的" | ✓ |
| zhoubond+solo | END_ZHOU 千里送猫 | ✓ |

**核验通过（角色层）。**

**⚠ 设计观察（建议级，非 bug）**：END_ZHOU 需 `zhoubond AND solo`（DSL flags 为 AND 逻辑），且整段 bond 路由只在 `sever` 下游可达（经 npm test 验证可达，属设计意图）。**注**：要求 zhoubond+solo 双 flag 是合理设计（既陪守夜、又托猫独行），narratively 自洽。副作用同其余 bond：非 sever 终章不兑现。详见 AUDIT-SUMMARY 建议项。

**⚠ 需注意（设计级）**：zhou_med（塞丹）与 zhoubond（守夜）是同一选择点的**互斥**两项（ch3.js:184-185）。塞丹给 zhou_med（回收剑穗线），守夜给 zhoubond（END_ZHOU 线）。玩家无法同时拿到——即"想看 END_ZHOU 就拿不到剑穗回收"。这是合理取舍，但两条都很动人，玩家可能错过其一而不自知。

## 七、一致性核对（逐章）

- **ch0**：达标。"天大的事，睡醒再说"、塞热馒头暖场。
- **ch1**：达标。烤红薯+主题台词+"放剑二十年"首露。
