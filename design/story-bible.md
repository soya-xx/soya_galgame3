# 《剑神三千年》故事圣经

> 一句话卖点：全宗门都当你是废柴，只有一只猫蹲在你窗台上，叫你三千年前的名字。

- 类型：男性向 龙傲天 修仙 单女主 视觉小说
- 女主：向向（Soya）——猫娘，奶白长卷发、猫耳猫尾、蓝瞳、金铃铛颈圈（皮套素材为准）
- 主角：玩家取名（默认"林惊澜"），无立绘（玩家视角），CG 中可出现：黑发束高马尾、灰青外门弟子袍，终章白衣
- 玩法定位：每个时间点都有理由玩下去——倒计时压着你、谜团勾着你、下一个爽点等着你、向向的下一场戏馋着你、坏结局也给你情报

## 一、世界观（一次只教一条规则）

- 修行分境界：练气 → 筑基 → 金丹 → 元婴 → 化神 → 返虚 → 合道。玩家只需要知道"练气垫底，合道封顶"。
- 三千年前，天下第一剑修人称"剑首"。他没有宗门，一人一剑一猫，住在听雨崖。
- 剑首飞升当日，被唯一的师弟顾长生一剑穿心，魂飞魄散。世人只知道：剑首飞升失败，尸骨无存。
- 顾长生如今是"玄天圣教"圣主，统治修行界。每六十年办一次"飞升祭"，各宗门进献天才弟子，说是"送他们登天"。
- 剑首养过一只小灵猫，名叫向向。她看着他死，没能做任何事。之后三千年，她修成大妖，在人间一寸一寸找他的魂。
- 本作开局：她找齐了。

## 二、主角与人物弧光

### 主角（玩家命名）

- 欲望（want）：查清当年真相，杀顾长生。
- 伤口（wound）：被这世上唯一信任的人杀死，死时身边只有一只猫。
- 面具（mask）：冷淡、毒舌、"谁都别靠近我"，把所有善意都当成交易。
- 需要（need）：允许有人留在身边；承认"变强"填不上"一个人"。
- 弧光：从"力量解决一切，人都会背叛"——到终章宁可斩断契约变弱，也不肯再看着身边的人替自己死。英雄之旅的"最深的洞穴"就是他的旧伤口：又一次被信任的人（宗门）出卖。

### 向向（Soya）

- 欲望：把三千年攒下的一切还给主人，然后悄悄退场。"我只是只猫，不配站在剑首身边。"
- 伤口：三千年前在听雨崖，她只能看着，连他的剑都叼不动。
- 面具：粘人、贪吃（鱼干狂热）、咋咋呼呼、永远在笑。
- 需要：被告知"你不是报恩的，你是我回来的理由"。
- 弧光：从"为他烧光自己也甘愿"——到真结局学会"活着站在他旁边"，而非死在他前面。
- 说话习惯：句尾偶尔带"喵"（紧张或装可爱时），称呼主角"主人"，急了会直接叫名字；谎话说不圆，撒娇一流，难过时会把耳朵压下去。

### 顾长生（玄天圣主，反派）

- 欲望：维持"天"不塌。他与天道做了交易：每六十年献祭天才，换天柱不倒。
- 伤口：他真心敬爱师兄。杀师兄那一剑，是"天"开出的第一笔价。
- 面具：救世主。白衣温言，永远悲悯。
- 黑暗镜像：他就是"选择了力量、身边空无一人"的主角——END_ASH 结局里玩家会亲自变成他。
- 弧光（真结局线）：被击败后求主角把他的剑插回听雨崖。"师兄，我守了三千年，守累了。"

### 沈青澜（宗门第一天才，打脸对象→可转化盟友）

- 欲望：赢。沈家把他当投资品，输一场就降一等。
- 伤口：十岁那年，输给堂兄，被罚跪祠堂三天，从此"输"等于"死"。
- 面具：傲慢，嘴上全是"废物也配"。
- 弧光：被主角碾压后第一次发现"输了天没塌"；圣教点名要他上飞升祭时，他第一次违抗家族（救沈线）。终章可与主角并肩。

### 柳长青（执法长老）

- 表面：铁面酷吏，逮着主角违规就罚。
- 真相：柳家先祖三千年前魔潮里被剑首所救，立了家训：世代守着剑庐残卷，等剑归来。他验了主角三次，第三次看见秋水剑意，当场下拜："柳家，等了你三千年。"（全游戏第一滴男人泪式爽点）
- 弧光：从守规矩的人，到为真相烧掉自己执法令的人。

### 赵虎（外门恶霸，第一个打脸祭品）

- 沈青澜的狗腿，靠克扣外门月例养自己。功能：序章施压、第一章被公开打脸。结尾彩蛋：转行去伙房烧火，被老周头使唤。

### 老周头（杂役院老头，主题陈述者）

- 年轻时是外门天才，为了照顾瘫了的娘放下剑。全宗笑他，他活得最自在。
- 主题台词（第一章）："剑再快，也得有人给你递碗热水啊。"
- 功能：救猫咪式暖场、黑夜灵魂时递鱼干的人。

### 玄一（圣使，中段BOSS）

- 圣主座下首徒。礼数周到，眼里没有活人，只有"祭品成色"。

## 三、状态变量与分支逻辑（玩家不可见）

| 变量 | 含义 | 增减来源 |
| --- | --- | --- |
| `jian`（剑心） | 杀伐果断/力量优先 | 选狠的、快的、独的选项 |
| `ban`（羁绊） | 与向向的羁绊 | 鱼干、摸耳朵、说真话、护她 |
| `truth`（真相） | 收集到的真相碎片 0-8 | 查账、验尸、剑冢碑文、柳家残卷、圣使醉话、梦境、顾长生书信、面板异常 |

分支红线（方法论硬约束）：
- 禁止"选A进A线"。所有结局判定都是 组合条件（见结局矩阵）。
- 选项按钮只写短行动，不写理由、不写数值、不写后果提示。
- 每个选择后 3 个节点内必须兑现可见后果：表情变化 / 台词反馈 / 局势变化 / 情报入账，至少一项。
- 数值永不直接展示给玩家；玩家从向向的耳朵、尾巴、称呼变化感知羁绊。

## 五、爽点清单（必须全部兑现）

1. 序章：剑骨一夜重铸，面板亮出"真实底蕴：返虚剑意"——废柴皮、神装底。
2. 一章：演武场一剑断三十年老石桩，全场死寂；赌局赢走赵虎三个月例钱。
3. 一章：月下现形——猫变绝世美少女，先发制人的"恋爱暴击"。
4. 二章：试剑大会，沈青澜全力一剑，你两根手指夹住（锋芒线）或侧身半步让他剑脱手（藏拙线）。
5. 二章：拍卖会30灵石捡漏"废铁断剑"，当场认出是自己三千年前佩剑"听雨"的剑尖。
6. 三章：剑冢秘境，上万柄古剑齐齐出鞘三寸，向你低头——万剑朝宗。
7. 三章：柳长青验明剑意，雨夜执法堂前单膝跪地："柳家，等了你三千年。"
8. 四章：绝境反杀——断剑斩落圣使一臂；全宗门看清他们卖掉的是谁，集体跪求原谅（迟来的认知爽）。
9. 终章：万剑归宗——"我的剑从来不在鞘里，在人间。"天下之剑破空来朝，连圣主佩剑都倒戈离鞘。
10. 终章：打脸天道——"天要塌就让它塌。我来扛。"

## 六、章节结构与场景清单

> 每章 ≥3 张CG；每章结尾必须改变压力/目标/债务/关系/危险中至少一项；每~60秒阅读一个刺激点。

### 序章「雨夜有猫叫我的名字」（约70节点）
1. 雨夜杂役院：受罚搬砖，赵虎克扣月例+三日逐出倒计时（危机）→ 老周头塞热馒头（暖）
2. 破屋；窗台上的猫（CG：cg_cat_window）；猫开口叫真名（催化剂）
3. 争论+选择①：『让它进来 / 关窗』（关窗→它淋雨等到天亮，羁绊补偿戏）
4. 向向自述三千年（克制，只给三成信息）；选择②：『签契约 / 再问清楚 / 赶她走』（赶两次→END_REFUSE）
5. 契约成，剑骨重铸之夜（CG：cg_bone_reforge），面板觉醒（爽点1）
- 章末钩子：明天，演武场点名。

### 第一章「扮猪吃虎」（约110节点）
1. 晨：向向赖床争夺枕头角（日常糖）；月例风波，赵虎挑衅，设赌局
2. 演武场：选择③『接赌局 / 忍下来』→ 一剑断桩（CG：cg_stump_cut，爽点2）打脸赵虎
3. 老周头主题陈述；柳长青第一次盘问（埋线）
4. 夜：后山湖边练剑顿悟"秋水"（CG：cg_insight_lake）；面板第一次小异常（伏笔：消耗来源）
5. 月圆：向向现形（CG：cg_moon_reveal，爽点3）；选择④：『盯着看 / 移开眼』+ 摸耳朵微选择
- 章末钩子：试剑大会七日后开打，内门名额=留下的唯一路。

### 第二章「试剑大会」（约130节点）
1. 大会规则+沈青澜出场（傲慢全开）；向向藏在兜帽里当"挂件"观赛
2. 连胜三场（快节奏蒙太奇）；选择⑤（核心）：对沈青澜——『藏拙 / 锋芒』
   - 藏拙：让他剑脱手，"侥幸"赢（CG：cg_hidden_win）→ 沈青澜怀疑反复回味，柳长青起疑+1
   - 锋芒：两指夹剑（CG：cg_blaze）→ 名动全宗，圣教耳目记下你
3. 拍卖会：30灵石捡漏断剑"听雨"剑尖（CG：cg_auction，爽点5）；沈家管事抬价羞辱→反杀
4. 柳长青第二次试探；选择⑥：『露一手真的 / 装到底』（真相线/柳盟线分水岭）
5. 夜：向向发现剑尖会"哭"，抱着它睡着（糖里藏刀：她替剑回忆）
- 章末钩子：圣使玄一入宗的仪仗已到山门。

### 第三章「万剑朝宗」（约130节点）
1. 圣使驾临，全宗跪迎；玄一点名见"试剑大会那个外门弟子"（按藏拙/锋芒不同对话）
2. 迎仙楼夜宴：座次试探，选择⑦：『上座 / 末座 / 不去』；圣使醉话掉真相碎片
3. 剑冢秘境开启（大会奖励）：万剑朝宗（CG：cg_sword_tomb，爽点6）；碑文真相碎片；沈青澜在秘境遇险，选择⑧：『救 / 不救』（救沈线）
4. 柳长青雨夜下拜（CG：cg_liu_kneel，爽点7）；柳家残卷=真相大块
5. 中点炸弹：向向宴后昏倒（CG：cg_collapse）；面板自检（CG：cg_panel_truth）——每次顿悟烧她妖丹；选择⑨（揪心）：『质问她 / 装不知道 / 从此不用面板』
- 章末钩子：圣使留下名册：飞升祭，三日后点人。

### 第四章「天倾」（约120节点）
1. 名册上有沈青澜；救沈线：他深夜来求你带他逃，家族要他"光荣赴死"
2. 圣使摊牌：他认出了剑意，开价——『跟我回圣山 / 现在死』；选择⑩：『拔剑 / 周旋』
3. 宗门高层投票把你交出去（旧伤复发）；老周头和柳长青是仅有的反对票
4. 圣使出手（CG：cg_envoy_strike）；断剑斩其一臂（爽点8）但重伤垂死；向向燃丹（CG：cg_core_burn）——退回小猫，忘了你
5. 灵魂黑夜：屋顶，小猫，鱼干（CG：cg_rooftop）；老周头热水+主题回收；选择⑪：『为她活 / 为恨活』（影响终章台词与END_DEMON入口）
6. 柳长青烧执法令，带来剑冢钥匙；选择⑫：『反攻 / 带她走』（带她走+羁绊≥8→END_LEAVE）
- 章末钩子：飞升祭，明日午时。

### 终章「万剑归宗」（约110节点+结局群）
1. 集结：按 flags 决定谁与你并肩（沈青澜/柳长青/老周头送行/宗门赎罪团）
2. 攻飞升台；圣主顾长生现身，真相全揭（按 truth 数量给完整或残缺版本）
3. 高塔惊变：顾长生开价——把向向的妖丹放上祭坛，你来当新天，天下太平
4. 深挖（终极选择⑬）：『烧契约（必胜，她死）/ 斩契约（搏命，护她）』
5. 万剑归宗（CG：cg_wanjian，爽点9/10）→ 按矩阵进结局

## 八、文风红线（写作时逐条自检）

- 大白话。专有名词第一次出现就要当场能懂（境界用"垫底/封顶"锚定）。
- 禁止：不是…而是…、本质、范式、涌现、宏大叙事、接口、阈值、赋能 等AI味词。
- 每句台词 ≤42 显示字符，长想法拆成多次点击。
- 角色行为要像人：怕死、贪利、要面子、护短。主角毒舌但不中二宣言；向向撒娇但谎话说不圆。
- 旁白不带铭牌；具名角色全部有立绘+铭牌。
- 选项：2-3字到8字短行动；两边都像对的；选完3节点内兑现后果。
- 玩家名 {player} 全程使用，向向叫"主人"或直呼其名（羁绊高后）。

## 九、可玩性检查点（不好玩禁止验收）

- 任意一个存档点向后5分钟内必有：危机/反转/打脸/发糖/新情报 之一。
- 每章结尾必须有"明天会发生什么"的具体钩子（倒计时或预告）。
- 坏结局玩完不骂街：必给下一周目可用的情报+一句路线暗号。
- 第一次通关后，分支图要让玩家清楚"我还有什么没看到"。
