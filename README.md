# 剑神三千年

> 全宗门都当你是废柴，只有一只猫蹲在你窗台上，叫你三千年前的名字。

男性向龙傲天修仙视觉小说。单女主：向向（Soya）。玩家自由命名主角。

## 玩法规格

- 序章 + 五章主线 + 8 个结局（真结局×2 / 坏结局×4 / 隐藏×1 / 独断×1），1600+ 剧情节点
- 17 处关键选择，复杂分支条件（剑心/羁绊/真相 三轴隐藏变量 + 15 个剧情flag）
- 坏结局全部附带"情报奖励"，进入分支图情报页，服务下一周目
- VN 全套操作：历史（滚轮上滑）/ 自动 / 已读快进 / 分支回顾 / 快存快读（F5/F9）/ 9存档槽 / CG鉴赏 / 设置

## 运行

```bash
npm run serve   # http://127.0.0.1:8013/
```

## 检查

```bash
npm test        # 结构图完整性 / 8结局路线模拟 / 文风红线 / 体验钩子
```

## 目录

- `CLAUDE.md` — 开发准则（含资产铁律：旧图/废图永久归档、每图标注生成模型）
- `design/story-bible.md` — 故事圣经（救猫咪节拍、人物弧光、爽点清单、结局矩阵）
- `design/asset-spec.md` — 全部图像资产的生成规格与提示词
- `design/archive/` — 历史素材永久归档（旧图/废图，禁止删除）
- `design/asset-models.tsv` — 现役图的生成模型清单
- `web/` — 可直接静态托管的游戏本体
- `web/script/` — 剧本数据（DSL + 各章节点）
- `test/` — 自动化验收
- `ACCEPTANCE.md` — 用户标准逐条验收表
